Fonts bundled with Silk
=======================
All fonts in this folder are redistributed under open licences that permit
bundling with software.

SIL Open Font License 1.1 (OFL) — the large majority of these families.
  Full text: https://scripts.sil.org/OFL
Apache License 2.0 — Roboto and Roboto Condensed.
  Full text: https://www.apache.org/licenses/LICENSE-2.0
Ubuntu Font Licence 1.0 — Ubuntu Condensed.
  Full text: https://ubuntu.com/legal/font-licence

Sources: the Google Fonts project (https://github.com/google/fonts).

Several families are published upstream only as variable fonts, which the
WoW client cannot render. Those were instantiated to a single static weight
with fontTools; the outlines are unmodified otherwise. No font has been
renamed in a way that would misrepresent its origin.
