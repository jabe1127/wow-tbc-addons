# Icon assets

Three bars hung from the top edge — gold, teal, grey. The two shorter bars
leave rows beneath them: a spell-icon square under the teal, and two digits
stacked under the grey. Every element sits the same distance below its bar,
so the rows line up.

Flat, no gradients or outlines.

| File | Digit face |
|---|---|
| `jct-icon-*.png` | Arial-style grotesque. Neutral default. |
| `jct-icon-helvetica-*.png` | Helvetica-style. Slightly tighter bowl. |
| `jct-icon-round-*.png` | Rounder, more open — echoes the pill bar caps. |
| `jct-icon-narrow-*.png` | Condensed, taller-looking digits. |
| `jct-icon-small-*.png` | Digits removed, for 32px and below. |
| `github-banner.png` | GitHub social preview, 1280×640. |

Pick whichever face you prefer and rename it to `jct-icon-*` — nothing else
references these by name.

Each ships at 1024, 512, 256, 128, 64 and 32.
